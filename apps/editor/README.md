# Editor app (workspace)

This is the SvelteKit/Vite editor UI for `shadertoy-nodeeditor`.

Most development should be run from the **repo root** so workspaces build in the right order:

```bash
npm install
npm run dev
```

Docs live at the repo root. Start here: `README.md`. **Media / `iChannel` bindings** are edited in the inspector **Media** panel; see `docs/shader-pipeline.md`.
